2. KONSE FRAMEWORKS USE HUE HAIN? (FRAMEWORKS & LIBRARIES STATUS)
--------------------------------------------------------------------------------

IMPORTANT POINT (Presenter ko Judges ko batana hai):
"Is project me kisi bhi third-party external framework (jaise React, Angular, 
Vue, Bootstrap, Tailwind, ya jQuery) ka use NAHI kiya gaya hai."

KYU NAHI KIYA? (Reasoning for Judges):
1. Zero Runtime Dependencies: Na koi npm install, na node_modules, na build step.
2. Ultra-Fast Load Time: App pure web standards par bana hai aur 10ms ke andar load hota hai.
3. 100% Offline Resilience: College trips aksar remote locations par hoti hain jahan 
   internet nahi hota. Agar cloud database ya heavy framework use karte toh app network 
   fail hone par crash ho jata. Yeh app bina internet ke pura kaam karta hai.

BROWSER-NATIVE APIs (Jo frameworks se bhi powerful hain):
1. IndexedDB API      -> Real NoSQL transactional database running in the browser.
2. Web Storage API    -> localStorage dual-write backup engine.
3. Inline SVG         -> Custom bar charts bina Chart.js library ke.
4. Clipboard API      -> 1-click summary aur UPI ID copy karne ke liye.


--------------------------------------------------------------------------------
3. PROJECT KE SARE MAIN FEATURES (WHAT THE APP CAN DO)
--------------------------------------------------------------------------------

1. FRIENDS / MEMBERS MANAGEMENT:
   - Trip members ko add, inline-edit aur delete karna with optional UPI IDs.
   - Duplicate names prevention aur avatar initials badges.

2. 3 ADVANCED EXPENSE SPLITTING MODES (Main Innovation):
   - Mode 1: Equal Split ('all')
     Sabhi doston me barabar batwara (Hotel, Taxi, Dhaba).
   - Mode 2: Paid on Behalf of Someone ('single' / 1-on-1 Personal Spend)
     Jab Dost A ne Dost B ke personal kharche (shopping, medicine, ticket) pay kiye hon.
     100% share Dost B ke hisse me jata hai, baki sabhi doston par Rs. 0 rehta hai.
   - Mode 3: Selected Friends Custom Split ('custom')
     Agar group me se sirf 2-3 doston ne koi activity (Rafting, Go-karting) ki ho, 
     toh expense sirf unhi doston ke beech divide hota hai.

3. GREEDY TRANSACTION MINIMIZATION ALGORITHM:
   - Automatically sabhi debts ko calculate karta hai.
   - Mathematical guarantee deta hai ki chahe kitne bhi complex expenses hon, 
     payments hamesha AT MOST (N - 1) transactions me settle hongi.

4. TRIP BUDGET GOAL & REAL-TIME TRACKER:
   - Planned budget target (default Rs. 15,000, 100% editable anytime).
   - Real-time progress bar color badalta hai:
     * Normal (<80%)  : Teal Color
     * Warning (80%+) : Orange Color
     * Over-Budget    : Red Color ("Over Budget by Rs. X!")

5. DYNAMIC VISUAL ANALYTICS (SVG CHART):
   - Category-wise ya Member-wise expense breakdown bar chart bina kisi external library ke.

6. REAL-TIME SEARCH & MULTI-FILTER:
   - Description text search + Category filter + Payer filter.

7. SHARING & EXPORT SUITE:
   - 1-Click WhatsApp Share: Formatted text summary copy aur send karne ke liye.
   - Download Audit Report (.txt): Complete trip ledger file.
   - Export CSV: Excel / Google Sheets ke liye.

8. IN-BROWSER AUTOMATED QUALITY SELF-TEST SUITE:
   - DevTools console me 'runSelfTests()' likhte hi 23/23 unit tests pass hote hain.


--------------------------------------------------------------------------------
4. CODE KE IMPORTANT FUNCTIONS (VIVA / TECHNICAL QUESTIONS)
--------------------------------------------------------------------------------

File: js/app.js (Complete logic consolidated under 1000 lines, 8 well-structured sections)

1. calculateMemberShares(membersList, expensesList)
   - Core splitting math function.
   - Har member ka Total Paid, Fair Share, aur Net Balance (Paid - Share) nikalta hai.
   - 3 split modes (all, single, custom) ko handle karta hai.

2. calculateSettlements(memberBalances)
   - Greedy Two-Pointer Algorithm.
   - Largest debtor ko largest creditor se pair karta hai aur min(debt, credit) transfer karta hai.
   - Transactions ko <= N - 1 me minimize karta hai.

3. calculateTotalExpense(expensesList)
   - Pure trip ka total expenditure integer paise me compute karta hai.

4. distributeEqually(totalPaise, targetIds, accumulatorMap)
   - Uneven division me remainder paise ko distribute karta hai taaki 1 paisa bhi lost na ho.

5. initIndexedDB()
   - Browser me "TripSplitterDB" (v1) database initialize karta hai with 3 stores:
     'members', 'expenses', 'config'.

6. saveStateToStorage() & loadStateFromStorage()
   - Data ko IndexedDB me transactional write karta hai aur localStorage me backup rakhta hai.

7. formatRupees(paise) & rupeesToPaise(rupeeVal)
   - Money helpers jo Indian currency format (Rs. 1,234.56) aur paise conversion karte hain.

8. escapeHTML(str)
   - Security sanitization function jo XSS attacks (<, >, &, ", ') ko block karta hai.

9. renderApp()
   - Master UI renderer jo state change hone par cards, tables, charts aur modals update karta hai.

10. runSelfTests()
    - 23 built-in automated assertions jo math, invariants aur security ko verify karte hain.
